# 立志功能测试程序使用说明

本文档介绍如何使用立志功能的测试程序，这些程序独立于微信公众号平台，提供文字界面版的测试环境。

## 📁 文件说明

### 测试程序文件

- **`run_aspiration_tests.py`** - 测试启动器（推荐使用）
  - 提供友好的菜单界面
  - 可以选择运行不同类型的测试

- **`test_aspiration_cli.py`** - 手动测试界面
  - 文字界面版的立志功能测试程序
  - 可以手动输入立志内容和打卡内容
  - 实时查看AI反馈效果

- **`test_aspiration_auto.py`** - 自动化测试程序
  - 包含完整的测试用例
  - 自动验证立志功能的各个方面
  - 提供详细的测试报告

## 🚀 快速开始

### 方法一：使用测试启动器（推荐）

```bash
python run_aspiration_tests.py
```

然后根据菜单选择：
- `1` - 手动测试界面
- `2` - 自动化测试
- `3` - 特定测试
- `0` - 退出

### 方法二：直接运行测试程序

#### 运行手动测试界面
```bash
python test_aspiration_cli.py
```

#### 运行自动化测试
```bash
python test_aspiration_auto.py
```

#### 运行特定测试用例
```bash
python test_aspiration_auto.py test_goal_creation_basic
```

## 🔧 故障排除

### 常见问题

1. **导入错误**
   ```
   ModuleNotFoundError: No module named 'plugins.aspiration'
   ```
   **解决方案**：确保在项目根目录运行测试程序

2. **数据库错误**
   ```
   sqlite3.OperationalError: no such table
   ```
   **解决方案**：测试程序会自动创建临时数据库，如果仍有问题，请检查文件权限

3. **AI功能不可用**
   ```
   AI功能暂时不可用，使用默认回复
   ```
   **解决方案**：这是正常情况，测试程序会使用默认回复继续测试

### 调试建议

1. **查看详细日志**
   - 测试程序会输出详细的执行信息
   - 注意查看错误消息和堆栈跟踪

2. **单独测试功能**
   - 使用特定测试功能逐个验证
   - 从简单功能开始测试

3. **清除测试数据**
   - 手动测试界面提供数据清除功能
   - 自动化测试使用临时数据库，每次测试后自动清理

通过这些测试程序，您可以验证：
